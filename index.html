CI/CD Pipeline

A fully automated Jenkins pipeline taking code from commit to production — 10 stages with blue/green deployment and zero-downtime rollouts.

01
Code Commit
Developer pushes to a feature branch (e.g. feature/credit-score). Webhook triggers Jenkins automatically.
02
Maven Build
Jenkins compiles Java code and packages into a JAR. Pipeline stops immediately on compile failure — fail fast.
03
Unit Tests
JUnit + Mockito tests run. JaCoCo enforces 85%+ coverage. Any failure blocks the pipeline.
85%+ coverage required
04
SonarQube Analysis
Code quality gate: A rating required, zero critical issues. Scans for code smells, security vulnerabilities, bugs, and duplication.
A rating · zero critical issues
05
Docker Build
Multi-stage Dockerfiles produce lightweight images under 200MB. Tagged with version + build number for traceability.
06
Artifactory
Verified images pushed to private Docker registry. Separate repositories for dev, QA, and production.
07
Deploy → Dev + Integration Tests
Rolling EKS deploy via kubectl set image, pods replaced one-by-one. RestAssured end-to-end API tests run against dev.
08
Deploy → QA
QA environment for manual testing — UI scenarios, edge cases, regression checks by the QA team.
09
Blue/Green Production Deploy
New version deploys to green. Smoke tests run. ALB flips traffic instantly. Blue stays running as an immediate rollback option. Once stable, blue scales down.
Zero downtime · instant rollback
10
Slack Notifications
Team gets updates at each stage. Failures alert with logs. Successful prod deploys post the version and who approved it.
